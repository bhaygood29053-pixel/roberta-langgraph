## Autonomous remediation semantics

The current autonomous remediation path is:

```text
canonical failure
  -> source-bound weak concepts / complete Boss atoms
  -> source-grounded practice
  -> closed-source bounded candidate-memory retention
  -> failed-checkpoint + retention provenance binding
  -> provenance-bound curriculum-scoped LearnedConcept conversion (not yet persisted/promoted)
  -> atomic + Boss transfer verification
  -> persistence/promotion only after perfect transfer
  -> canonical retry
```

Candidate memory is unpromoted training state. It is not source evidence, an answer key, general durable memory, live state, CMIS/provider truth, policy authority, wallet authority, or execution authority.
